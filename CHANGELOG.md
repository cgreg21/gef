# Changelog

All notable changes to GEF are documented here. Versions follow Semantic
Versioning once public releases begin.

## 0.1.0 - Unpublished

Initial development release candidate.

- TypeScript and GTPL compiler foundations for GNOME Shell 51.
- Runtime foundations for GNOME Shell St actors and GTK4/libadwaita.
- `gef` CLI for checking, compiling, scaffolding and packaging extensions.
- EGO-oriented metadata and package validation.
- npm package metadata, compiler/runtime ESM exports and `npx` CLI support.
- CI coverage for unit tests, GTK integration and installation of the packed
  npm tarball.
